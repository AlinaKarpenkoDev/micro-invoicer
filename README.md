## 🌟 Key Features

- **Role-Based Access Control (RBAC):** Secure admin dashboard to manage users and platform metrics.
- **Cloud Storage Integration:** Real-time PDF generation and retrieval via Cloudflare R2.
- **Monorepo Architecture:** Shared types and configurations between Next.js client and NestJS API using Turborepo.
